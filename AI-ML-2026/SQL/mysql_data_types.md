# Data Types

| Datatype | Description | Usage |
|---|---|---|
| `CHAR` | String (0–255); stores characters of fixed length. | `CHAR(50)` |
| `VARCHAR` | String (0–255); stores characters up to the given length. | `VARCHAR(50)` |
| `BLOB` | String (0–65,535); can store a binary large object. | `BLOB(1000)` |
| `INT` | Integer: -2,147,483,648 to 2,147,483,647. | `INT` |
| `TINYINT` | Integer: -128 to 127. | `TINYINT` |
| `BIGINT` | Integer: -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807. | `BIGINT` |
| `BIT` | Can store x-bit values; x can range from 1 to 64. | `BIT(2)` |
| `FLOAT` | Decimal number with precision up to 23 digits. | `FLOAT` |
| `DOUBLE` | Decimal number with 24 to 53 digits of precision. | `DOUBLE` |
| `BOOLEAN` | Boolean values: 0 or 1. | `BOOLEAN` |
| `DATE` | Date in `YYYY-MM-DD` format, ranging from `1000-01-01` to `9999-12-31`. | `DATE` |
| `YEAR` | Four-digit year, ranging from 1901 to 2155. | `YEAR` |
