# AI-ML-2026

Python learning materials and hands-on exercises for the AI-ML-2026 track.
The project is organized by topic, from Python fundamentals through NumPy and
Pandas.

## Project structure

| Folder | Contents |
| --- | --- |
| `PythonFundamentals_1-3/` | Variables, control flow, loops, functions, strings, and collections |
| `PythonFundamentals_4-OOPS/` | Classes, methods, encapsulation, inheritance, and abstraction |
| `PythonFundamentals_5-File-IO/` | File handling, exceptions, and JSON examples with supporting sample files |
| `AI-ML-Data-JupyterLab/12_Numpy/` | NumPy arrays, indexing, reshaping, vectorization, and math |
| `AI-ML-Data-JupyterLab/13_Pandas/` | Pandas Series, DataFrames, and reading CSV/JSON data |

## Learning path

1. Work through the Python fundamentals in order.
2. Practice the object-oriented programming exercises.
3. Use the File IO examples with their sample text and JSON data.
4. Continue with the NumPy and Pandas notebooks.

## Resources

- [Kaggle](https://www.kaggle.com/) — datasets, notebooks, and data science practice.
- [Python Interview Questions](https://www.youtube.com/watch?v=WH_ieAsb4AI) — interview-focused practice and explanations.

## Notes

- The small text, JSON, and CSV files are sample inputs used by the lessons.
- Jupyter checkpoints, editor virtual documents, and file-browser databases are generated artifacts and are excluded from the project.
- Run Python scripts from their own lesson folders; file examples resolve sample paths relative to each script.
- Practice regularly and keep the examples small, readable, and focused on one concept.
